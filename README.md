# CART3R Mira Longa V2 (Android)

Aplicativo demonstrativo Android em Kotlin com sobreposição de mira longa **manual** e cálculo geométrico de rebotes ideais. Não modifica nem acessa dados de jogos; não tem mira automática.

## Compilação

Na aba **Actions** do GitHub, veja **Android - Compilar APK**. Após a execução bem-sucedida, baixe o artifact `CART3R-MiraLonga-v2-debug`, extraia o ZIP e instale `app-debug.apk` no Android.

## Avisos

Use apenas onde permitido. Ferramentas de sobreposição podem contrariar regras de jogos online. Nenhum acesso root ou dados privados é necessário. A sobreposição não garante precisão de tacadas.
